## Scenario Description
This console application models a transaction at the NTC Campus Cafe. It calculates coffee order subtotals, evaluates loyalty discounts, calculates reward pastry perks using integer division and modulo, and evaluates threshold conditions using comparison operators.

## How to Run
1. Open [DartPad](https://dartpad.dev).
2. Paste the contents of `bin/dart_exercises.dart`.
3. Click **Run**.
